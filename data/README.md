# Data directory

The data are intentionally tracked in semantic subfolders. Do not move them to the repository root: the canonical notebook validates these exact paths.

- `spatial/`: static grids and land-surface attributes.
- `hydroclimate/`: time-varying predictors.
- `grace/`: archived GRACE source workbooks.
- `benchmarks/`: external TWS products.
- `reproducibility/`: local CSV input representation used by the notebook.
- `auxiliary/`: supplied but non-canonical supporting files.
